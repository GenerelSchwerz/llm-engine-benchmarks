Write a Python 3.11 function `expand_ranges(spec: str) -> list[int]`.

The input is a comma-separated sequence of nonnegative integers or inclusive ranges such as `"1,3-5,5"`. Return sorted unique integers; for that example, return `[1, 3, 4, 5]`. Surrounding whitespace around comma-separated items is allowed. Reject an empty item, a descending range, a negative number, and malformed text with `ValueError`. An empty string should return an empty list.

Use only the Python standard library. Give the implementation and at least five runnable `unittest` cases, including a malformed input and a duplicate. Briefly explain any edge case you chose to handle.
